# OpenBible Cross-Reference Data

The file `openbible-cross-references.zip` was downloaded from
`https://www.openbible.info/labs/cross-references/` on July 18, 2026.

OpenBible.info describes the dataset as approximately 340,000 links identifying
shared themes, words, events, or people across biblical passages. The site says
the data draws primarily from public-domain sources, especially the Treasury of
Scripture Knowledge, and makes the dataset available under the Creative Commons
Attribution license.

This project uses only the reference graph and vote counts to locate candidate
Gospel parallels. Scripture text continues to come from the separately archived
KJV source. The graph is not treated as editorial approval: every selected
parallel remains subject to the Lady D manuscript judge, audit, and human proof.
